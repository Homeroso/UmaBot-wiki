


Esta guía te lleva paso a paso por tus primeros momentos en UmaCord.

  

---

## Paso 0: Reclamar recompensas de inicio (solo una vez)

  

Si eres nuevo, usa primero:

  

```

!start

```

  

Obtendrás **10.000 coins**, **3.000 carats**, **10 Umas** y **10 cartas** de forma gratuita. Solo puedes usarlo una vez por cuenta.

## Paso 1: Reclamar el daily

  

Cada día usa:

  

```

!daily

```

  

Obtendrás **2000 coins** (más bonus si mantienes la racha). El día 7 de racha te dan **50 carats**. Los carats son necesarios para el gacha.

  

---

  

## Paso 2: Conseguir Umas y cartas

  

Si tienes carats (por daily, Team Trials o que te los den), usa el gacha:

  

```

!pulluma

!pullcard

```

  

O multipulls para más eficiencia:

  

```

!multiuma

!multicard

```

  

Cada tirada cuesta **150 carats**. Necesitas al menos **1 Uma** para entrenar.

  

---

  

## Paso 3: Montar tu equipo

  

Añade Umas a tu equipo de entrenamiento:

  

```

!team add tokai teio

```

  

Puedes usar el nombre o el ID (ej: `tokai_teio`). Si tienes veteranos, podrás elegir herencia de stats.

  

Opcional: equipa cartas en cada slot desde `!team view` para mejorar el entrenamiento.

  

---

  

## Paso 4: Entrenar

  

Inicia una sesión de entrenamiento:

  

```

!train start

```

  

Elige un stat de enfoque (speed, stamina, power, guts, wit). Cada sesión tiene **24 turnos** y un cooldown de **1 hora**.

  

---

  

## Paso 5: Correr carreras

  

Durante el entrenamiento, puedes correr carreras:

  

```

!race

```

  

O con una Uma concreta:

  

```

!race 2

```

  

Las carreras dan monedas y bonus de stats. Las victorias mejoran el rango de retiro de tu Uma.

  

---

  

## Paso 6: Retiro y veteranos

  

Al completar los 24 turnos, la Uma se retira y pasa a veteranos. Puedes verlos con:

  

```

!veterans

```

  

Los veteranos se usan en:

- **Dream Trophy** (`!dt`) — liga semanal

- **Team Trials** (`!tt`) — PvP diario, 5 intentos

- **Friendly Race** — carreras con amigos

  

---

  

## Resumen de comandos esenciales

  

| Acción         | Comando              |
| -------------- | -------------------- |
| Reclamar daily | `!daily`             |
| Ver saldo      | `!balance`           |
| Tirar Uma      | `!pulluma`           |
| Tirar carta    | `!pullcard`          |
| Ver equipo     | `!team`              |
| Añadir Uma     | `!team add <nombre>` |
| Entrenar       | `!train start`       |
| Ver estado     | `!train status`      |
| Correr         | `!race`              |
| Ver veteranos  | `!veterans`          |
