


Consejos para sacar el máximo partido a tus sesiones de entrenamiento.

  

---

  

## Antes de entrenar

  

1. **Equipo completo**: Si puedes, usa 3 Umas con cartas equipadas. Las cartas aumentan las ganancias.

2. **Cartas Pal**: Reducen la bajada de ánimo. R (-1%), SR (-2%), SSR (-3%), UR (-5%).

3. **Clima**: Usa `!weather` para ver el clima actual. Pleasant Breeze (+5% todo) es ideal; Heat Wave (-5% stamina, +2% fail) es el peor.

  

---

  

## Elección del stat de enfoque

  

- **Speed**: Para carreras sprint y mile. Mejora también Power (~20%).

- **Stamina**: Para carreras medium y long. Mejora también Guts (~20%).

- **Power**: Para explosión. Mejora también Stamina (~20%).

- **Guts**: Para aguantar en momentos clave. Mejora Speed y Power (~20%).

- **Wit**: Para inteligencia. Mejora Speed (~20%).

  

Elige según las **aptitudes** de tu Uma y las carreras que quieras correr. Si tu Uma tiene aptitud A en Turf Mile, prioriza Speed.

  

---

  

## Gestión del ánimo

  

| Ánimo            | Acción recomendada                                  |
| ---------------- | --------------------------------------------------- |
| 1–2 (Awful/Bad)  | Usar `!recreation` si está disponible (5h cooldown) |
| 3 (Normal)       | Continuar; es el estándar                           |
| 4–5 (Good/Great) | Aprovechar; las ganancias son mayores               |
  

El ánimo puede bajar tras cada turno. Las cartas Pal ayudan a mantenerlo estable.

  

---

  
## Carreras durante el entrenamiento

  

- **Pre-Op / Op**: Más fáciles, buenas para acumular victorias y subir el rango de retiro.

- **G3 / G2 / G1**: Más difíciles; mejor cuando tengas buenos stats o estés en turnos avanzados (la dificultad baja hacia el final).

  

Cada victoria suma **50 puntos** al rating de retiro. Vale la pena intentar ganar varias carreras.

Al graduar (completar 24 turnos), recibes **carats** según el rango final: G ~5, A ~25, SS+ ~50, UF1 ~110. Cuanto mejor el rango, más carats.

---

  
## Clima y timing


El clima cambia cada **3 horas** y es global. Si ves Heat Wave o Storm, puedes esperar un poco antes de `!train start` para que cambie (opcional).


_Las skills de las cartas pueden hacer que los efectos del clima sean aún mayores, o directamente invertir los efectos negativos (WIP)_

---

  

## Resumen rápido

  

1. Equipa cartas, sobre todo Pal.

2. Revisa el clima con `!weather`.

3. Elige el stat según aptitudes y carreras objetivo.

4. Usa `!recreation` cuando el ánimo esté bajo.

5. Corre carreras para mejorar el rango de retiro.
