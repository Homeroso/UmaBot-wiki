
  

UmaCord usa tres tipos de monedas. Cada una tiene usos específicos y fuentes de obtención distintas.

  

---

  

## Monedas

| Moneda          | Uso principal                                    |
| --------------- | ------------------------------------------------ |
| **Coins** 🪙    | Entrenamiento, carreras, ascensión de Umas       |
| **Carats**  🥕  | Tiradas en el gacha                              |
| **Clovers**  🍀 | Ascensión de Umas (sustituyen copias duplicadas) |
  

---

  

## Comandos de economía

### `start` / `!start`  

Reclama las **recompensas de inicio** (solo una vez por cuenta):

- 10.000 coins

- 3.000 carats

- 10 Umas (multipull gratuito)

- 10 cartas (multipull gratuito)

![[Start.png]]
### `balance` / `!balance`

  

Muestra tu saldo actual de coins, carats y clovers.

  ![[Balance.png]]

### `daily` / `!daily`

  

Reclama tus recompensas diarias. Solo puedes usarlo **una vez cada 24 horas**.

  ![[daily.png]]

- **Base**: 2000 coins

- **Bonus por racha**: +100 coins por cada día consecutivo (día 2 = 2100, día 3 = 2200, etc.)

- **Bonus día 7**: +50 carats adicionales

  

Si pierdes un día, la racha se reinicia a 0.

  

---

  

## Fuentes de ingresos
_(Temporal)_

### Coins

| Fuente            | Descripción                                               |
| ----------------- | --------------------------------------------------------- |
| Daily             | Recompensa base + bonus racha                             |
| Carreras abiertas | Durante el entrenamiento (Pre-Op, Op)                     |
| Dream Trophy      | Recompensas por participar en carreras de la liga semanal |

### Carats

| Fuente             | Descripción                                     |
| ------------------ | ----------------------------------------------- |
| Daily (día 7)      | 50 carats al completar racha de 7 días          |
| Team Trials        | 1 carat por victoria (hasta 5 intentos diarios) |
| Dream Trophy       | Obtienes carats según tu desempeño              |
| Carreras G1        | 5 (1º), 3 (2º), 1 (3º) carats por carrera       |
| Graduación de Umas | Obtienes carats según su rango final            |
  
### Clovers


| Fuente            | Descripción                                                      |
| ----------------- | ---------------------------------------------------------------- |
| Cartas duplicadas | Al tener una carta al máximo de limit break y obtener otra copia |
| Umas duplicadas   | Al tener una Uma con 5 estrellas y obtener otra copia            |



---
## Consejos
  

1. **Reclama el daily cada día** para mantener la racha y conseguir los 50 carats del día 7.

2. **Team Trials** es la forma principal de conseguir carats de forma recurrente (5 intentos diarios).

3. **Clovers** son escasos; úsalos para ascender Umas raras cuando no tengas suficientes copias.
