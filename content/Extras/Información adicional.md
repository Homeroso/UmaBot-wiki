## Comandos: Slash vs Prefix

  

UmaCord soporta dos formas de ejecutar comandos:

  

| Tipo       | Ejemplo        | Descripción                                    |
| ---------- | -------------- | ---------------------------------------------- |
| **Slash**  | `/train start` | Comandos nativos de Discord con autocompletado |
| **Prefix** | `!train start` | Comandos con prefijo `!`                       |

  
### Alias de prefix

  

- `!dt` → `!dreamtrophy`

- `!tt` → `!teamtrials`

  

### Ejemplos equivalentes

  

| Slash                      | Prefix                 |
| -------------------------- | ---------------------- |
| `/daily`                   | `!daily`               |
| `/train start`             | `!train start`         |
| `/team add uma:tokai_teio` | `!team add tokai teio` |
| `/race slot:2`             | `!race 2`              |
| `/dreamtrophy view`        | `!dt view`             |
| `/teamtrials setup`        | `!tt setup`            |
