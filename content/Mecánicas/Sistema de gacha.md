El gacha utiliza un sistema de pesos para determinar qué rareza obtienes. Además, cuenta con un sistema de **Pity** para asegurar que eventualmente obtengas los mejores resultados.
Ten en cuenta que podrás consultar los banners disponibles en cualquier momento haciendo uso de [/gacha](../Comandos/Gacha) 
### Probabilidades Base para Umas

El sistema cuenta con cinco rarezas posibles para cada personaje, cada una con su propia probabilidad de salir al tirar en el gacha usando [/pull](../Comandos/Pull) o [/Multipull](../Comandos/Multipull), de la siguiente manera:

| Rareza UMA    | Probabilidad (%) |
| ------------- | ---------------- |
| **Legendary** | 0.5              |
| **Epic**      | 3.5              |
| **Rare**      | 11               |
| **Uncommon**  | 35               |
| **Common**    | 50               |

### Probabilidades Base para cartas

En el caso de las cartas obtenidas usando  [/pullsupp](../Comandos/Pullsupp) o [/pullsuppmulti](../Comandos/Pullsuppmulti), existen cuatro rarezas disponibles:

| **Rareza support** | **Probabilidad (%)** |
| ------------------ | -------------------- |
| **UR**             | 1                    |
| **SSR**            | 9                    |
| **SR**             | 30                   |
| **R**              | 60                   |

### 🛡️ Pity System 
  
El sistema de Pity ayuda a los entrenadores con menos suerte:

1. **Soft Pity (Tirada 50+)**: A partir de la tirada 50 sin obtener una rareza máxima (**Legendary** o **SSR/UR**), la probabilidad de estas aumenta gradualmente en un **0.5% por cada tirada**.

2. **Hard Pity (Tirada 90)**: Si llegas a la tirada 90 sin el premio mayor, la siguiente tirada lo garantiza al **100%**.

3. **Reset**: El contador de pity se reinicia a 0 en cuanto obtienes un item de la rareza máxima.
